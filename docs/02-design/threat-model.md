# Threat model — API Microservice

> **AI-DLC phase:** `02-design`  ·  **Method:** STRIDE + DREAD prioritization
> **Author:** vladeParica  ·  **Date:** 2026-11-05

## 1. Scope and assets to protect
- User PII (name, email) — see [data-classification](../00-project/data-classification.md).
- Database credentials.
- Service availability.

## 2. Data-flow diagram
See [C4 container](../architecture/c4-container.md): client → API → PostgreSQL.

## 3. STRIDE analysis
| Category | Threat | Affected component | Mitigation |
|---|---|---|---|
| **S**poofing | Anonymous clients call any endpoint | API | **Gap:** no auth in archetype; add middleware per service |
| **T**ampering | SQL injection | Repository | Parameterized queries generated by sqlc |
| **T**ampering | Mass assignment via extra JSON fields | Handler | `DisallowUnknownFields` + explicit `CreateParams` |
| **R**epudiation | Actions cannot be traced | Middleware | Access log with `request_id`; no actor identity yet |
| **I**nformation disclosure | Internal errors or stack traces in responses | Handler, Recoverer | Generic `500` message; details only in logs |
| **I**nformation disclosure | Credentials in repo or logs | Config | Env injection; DSN never logged |
| **I**nformation disclosure | Plain-text DB traffic | Postgres pool | `DATABASE_SSLMODE=require`/`verify-full` in production |
| **D**enial of service | Slowloris / large bodies | Server, httpx | Header/read/write timeouts; 1 MiB body limit |
| **D**enial of service | Request flooding | API | **Gap:** rate limiting delegated to ingress |
| **E**levation of privilege | Container breakout | Runtime | Distroless, non-root user, no shell |

## 4. DREAD prioritization
| Threat | Damage | Reproducibility | Exploitability | Affected users | Discoverability | Total |
|---|---|---|---|---|---|---|
| No authentication | 8 | 10 | 10 | 10 | 10 | 48 |
| No rate limiting | 6 | 10 | 8 | 10 | 7 | 41 |
| Plain-text DB traffic (misconfig) | 7 | 5 | 4 | 10 | 3 | 29 |
| User id enumeration | 5 | 10 | 9 | 10 | 8 | 42 |
